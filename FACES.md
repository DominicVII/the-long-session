# Faces — One Nation, Under, ME.

Hair stayed. Faces were rebuilt so they match the body they sit on.

## What changed
- **Masc / fem skulls** — separate sculpt families (jaw, brow, cheeks, chin).
- **Look morphs** — `faceW`, `jawW`, `browH`, `noseL`, `lipF`, `cheek`, `age` rolled per person.
- **Painted face** — oval face plate, real eye stack (sclera / iris / pupil / catchlight), brows from hair colour, nose + nostrils, lips + philtrum, age lines; feathered into skull skin tone.
- **Head assembly** — skull scale follows frame + morphs + build; face dome hugs the skull; cheeks / chin / modest nose / lips in the same skin so it is not a sticker.
- **Remesh** — existing people remesh once (`_faceVer = 2`) so old heads update in a running save.

## Notes
- Eyes for blink / speak anchors stay tiny; lids still close over the paint.
- Face atlas quality still follows gfx / crowd (`hi` / `mid` / `lo`).
