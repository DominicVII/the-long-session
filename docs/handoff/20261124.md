The title is drawn before IndexedDB answers and was never redrawn, so it said day 516. ## Small fixes
- **Nightly saves.** The save engine waited for "quiet" before every slice, and an open card counts as not quiet. The morning page after a night therefore parked that night's save until the card was closed. Headless runs never close it. Now only movement (G.moving, G.pendingNight) makes a slice wait. A queueSave that is turned away is owed (G._saveOwed), and a 1 s poll pays it once nothing is moving.
- **Journal "Day undefined".** journal() writes `day`; older writers wrote `d`. The pane reads both and adds the hour.
- **Talk choices at 1280x720 after Continue.** The talk panel scrolls to the first usable choice. It does this when the choices are drawn, while the line streams in, and every 700 ms while open. It stops once you scroll the panel yourself.

## Round 2: Academy papers (engine and data are Jupiter's; the reading UI is Neptune's)

The papers live in `G.academy = {v:1, n, lastDay, p:[paper...]}`. Only a seed and some numbers are stored per paper; the
text is rebuilt from them each time a paper is opened, and the rebuilt text is identical after a reload.

The stored record, roughly 150 bytes per paper:
```
{ no: 12,            // the paper's number; numbers are never reused
  d: 535,            // the day it was published
  b: "eo",           // the institution key; see onumAcademy.bodies
                     //   acad, rb, pi, eo, ss, ma, sa, id, uc, ec, hs
  s: 2893745123,     // the seed; every textual choice comes from it
  by: 3, sc: 1,      // the scholar index and the school index (the names come from the seed)
  tp: "m2" | ti: 1,  // the topic: an Academy discovery id (INQ_BY), or a domain topic index
  dm?: "econ",       // optional domain override
  k: [N, conf, eff, dissent, costK, years, guilder?, treasury?],   // the key numbers
  c: [9, 10, 11],    // citations: earlier papers in the same domain
  rb?: 7,            // the paper it replies to
  st: "held"|"failed", fb?: 15,   // its standing; if failed, the paper that overturned it
  rev?: 1,           // a discovery that changes society
  dec?: {o: 0|1|2, d: 540} }      // the cabinet's decision: 0 high, 1 moderate, 2 none
```

API, which reads only and never changes the save except through `decide` and `publish`:
- `onumAcademy.list()` returns `[{no, day, institution, field, title, school, scholar, cites, replyTo, status,
  overturnedBy, decided, revolutionary}]`.
- `onumAcademy.get(no)` returns a copy of the stored record.
- `onumAcademy.text(no)` returns the full paper as markdown-ish plain text:
  - `# Paper No. N: Title`, then an `Institution:` line;
  - then `## Abstract`, `## Research Question`, `## Background Literature` (cites "Paper No. N (day D, Institution)"),
    `## Methodology`, `## Findings`, `## Competing Interpretations`, `## Counterarguments`, `## Policy Recommendations`,
    `## Risk Assessment`, `## Forecast`, `## Public Response`, `## Cabinet Relevance`, `## Historical Significance`.
  - Citation links: in the text, match `/Paper No\. (\d+)/`.
- `onumAcademy.title(no)`, `.schools()`, `.scholars()` (ranked by citations and papers), `.prestige()` (institutions),
  `.failed()` (the archive of failed theories), `.decisions()` (open paper numbers), `.decide(no, 0|1|2)`, `.bodies`.
- `.open()` is Jupiter's plain stand-in reader, the phone app "Papers" (soc-acad). Neptune's paged view and library can
  replace it by overriding `pbAppGo("soc-acad")`.

Papers are published:
- for every Academy discovery (`inqDiscovered`);
- by one state body about every third day, on a deterministic schedule.

The archive keeps the newest 400 papers.

People (`window.onumPeople`):
- `story(id)` is a stable life story, the same text that "tell me about yourself" returns;
- `opinions(id)` are views held before you meet;
- `remembers(id, n)` returns real journal events by day;
- `recall(id)`, `reply(id, text)`, `gossip()` (people talking to each other; the log is `G.tkTalk.log`, at most 24 entries),
  `dissent(votes, v)`, `prompt(id)`.
